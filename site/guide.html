Overview

SwiftSaleApp helps Whatnot sellers speed up packing and shipping with live (or manual) bin assignments, label annotation, and an auto-built mailing list. If live capture isn’t available, the Manual Fallback flow covers you with the same downstream features.

1) Installation

  1. Download the Windows installer from the Download section.
  2. Run the installer (no admin needed; installs to your user AppData).
  3. Launch SwiftSaleApp from the Start Menu or Desktop shortcut.

SmartScreen warning? Click More info → Run anyway.

2) Activation & Tiers

  1. On first launch, enter a valid email. Your install ID and tier sync automatically when available. All users begin in free Starter on first run.
  2. Paid users receive an activation code via email within 24 hours (typically ~14 hours).
  3. To enter a promo code, press Ctrl + Alt + D (dialog label: Enter Promo Code).
  • Starter: Free — up to 20 bins; core features (chat tools, sell-rate, top buyers, label annotation, mailing list).
  • Bronze: $29.99/mo — up to 50 bins.
  • Silver: $69.99/mo — up to 150 bins.
  • Gold: $99.99/mo — up to 600 bins, 2-device limit per email, priority support.

Manage upgrades/downgrades on the website: Manage Subscription.

3) Capturing Buyers (Live & Manual Fallback)

Live capture: When enabled, SwiftSaleApp automatically detects buyer usernames during your show and assigns bins in real time. There is a toggle in Settings → Capture to enable/disable auto-capture.

Manual Fallback (always available): Copy/paste the winning username into the Bidder List. SwiftSale assigns bins automatically. All features (annotation, mailing list, reports) work the same.

No Whatnot login required. We operate on live event data (when available) and manual entry.

4) Bin Assignments

  1. As buyers win/purchase, each username gets a bin number (auto or manual).
  2. Assignments are idempotent—the same buyer keeps the same bin for the entire show.
Duplicate-paste safeguard

In SwiftSaleApp V4, the Add Bidder button turns yellow if the same username is pasted consecutively. It still records the entry but prompts a quick double-check. Paste the correct winner next; bins continue sequentially and the button returns to green.

5) Label Annotation (Post-Show)

  1. Download your Whatnot shipping labels PDF after the show.
  2. In SwiftSaleApp, click Annotate Labels and select that PDF. The app overlays each label with the buyer name and bin number.
  3. Save or print the annotated PDF. Matching labels to assigned bins in real time speeds packing significantly.

Teams report up to ~57% faster packing when using annotated labels with bins.

6) Mailing List & Reports

  • Mailing List: A mailing list is auto-built each time you annotate labels. Existing customers are deduped; new spend is added to their profile. (Planned: USPS integration to generate promo/marketing shipments to selected customers.)
  • Top Buyers: See top customers per show and high spenders. Clicking a top buyer copies a ready-to-paste chat message. Customize templates in Settings → Messages, then Save Settings.
  • Sell-Rate: Live snapshot of show performance — items per minute and projected totals over 2–3 hours.

7) Device Limits & Sync

  • Gold: Enforced 2-device limit per email. If you replace hardware, contact support to release an old device.
  • Install/tier syncing runs automatically based on your email and subscription status. All users begin in Starter on first run.

8) Shortcuts & Best Practices

  • Open promo dialog: Ctrl + Alt + D (Enter Promo Code).
  • Auto-capture toggle: Settings → Capture → Auto-capture usernames.
  • Keep usernames consistent: The duplicate-paste warning (yellow button) helps you avoid accidental repeats.

9) Troubleshooting

Promo code says invalid
  • Double-check spelling/spaces. Try again via Ctrl+Alt+D.
  • Make sure you’re on the same email used for purchase.
  • If still failing, send your Install ID and code to support@swiftsaleapp.com.
Labels didn’t annotate or look blank
  • Open the original Whatnot PDF via Annotate Labels (not a scanned or flattened print).
  • Re-download the labels from Whatnot and try again.
Live capture isn’t working
  • Enable Settings → Capture → Auto-capture usernames.
  • Use Manual Fallback (paste usernames) if live capture is unavailable.
Hit device limit (Gold)

Email support@swiftsaleapp.com with your Install ID to release an old device.
